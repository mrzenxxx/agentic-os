Ограничения: только собственный stdio-сервер, никаких сетевых MCP-транспортов,
БД, очередей и параллельных прогонов. Реальные данные и трейсы не коммитятся.
Новые промпты создаются новой версией, v1/v2 сохраняются.

Проверено на финальном коде: production build, inspect (5 tools / 4 resources),
браузерный запрос (HTTP 200, approve 10/10 за два раунда, MCP и локальный tool
отображаются в UI, план записан дословно), eval 5/5 PASS без изменений кейсов.
Отдельно проверены фильтрация tools, ошибка harness, ошибки схемы и файловой
записи MCP, а также markdown-подзаголовки внутри одной записи дневника.
После закрытия прогонов дочерних MCP-процессов не остаётся.
