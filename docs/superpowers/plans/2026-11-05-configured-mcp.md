# V5: внешние MCP-серверы из конфига

Цель: подключать stdio MCP-серверы записью в конфиге без кода интеграции.

Архитектура: общий lifecycle читает массив описаний, создаёт MCPServerStdio и закрывает
все процессы в finally. Tools и их схемы обнаруживает Agents SDK, он же добавляет
namespace. Чтение доступно при планировании, внешняя запись — после approve.
Основной saver сохраняет обязательный одиночный вызов; exporter делает запрошенные
копии. Ревьюер без tools, при отключении markdown-health контекст читает filesystem.
